# SimulationBar

Team place chances from the meet simulation, as one bar split by place.

- `.simbar`: 30px tall, `radius-md`, `line` border. Each `span` is a place, width = its chance, on `panel`. The most likely place is `.best`: `hawk` with `hawk-ink` text.
- Label inside the segment only when it fits; drop the label on thin segments.
- Put median points with the 8-in-10 range above, teams that usually finish ahead below. Scores are unofficial.
