# WhosGoing

The admins' entry panel: the roster with Yes, Maybe and No for one upcoming meet.

- A `.dh-panel` (620px, `radius-xl`) over a 55% black scrim. Rows split by `line` hairlines; name left, three 36px chips right.
- Pressed Yes and Maybe use `sel-bg`; pressed No fills `muted`. A second tap clears.
- A `small` `faint` note under a name flags a change not yet in the projections.
