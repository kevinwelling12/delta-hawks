# TimeHero

The top of an athlete page: the expected time huge, then the likely range on a strip.

- `.big` in the `time-hero` style. The caption (`.cap`) says which meet and the range in words.
- `.strip`: a `line` track, the `hawk` range band (with `band-edge` outline in light), a `.mid` marker and a dashed `.pr` line. Markers on the band are always `hawk-ink`.
- Position by percent of the track. Label both ends. Always add the legend.
