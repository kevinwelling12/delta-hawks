# SignInCard

The sign-in gate shown before the portal loads, and the pull-to-refresh pill.

- Centered column, 520px max. h2 title, one `sub` line, one `.dh-go` button.
- Errors replace the text in place and name the error code and the step. "Loading..." shows only after 600 ms.
- The pill (`radius-pill`, `sel-bg`, `shadow-pill`) appears only in the home screen web app.
