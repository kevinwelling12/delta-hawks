# ReportBadges

Small uppercase tags in the meet report and race history, each a word that names the status.

- `.rb` base: `report-badge` style, `radius-sm`, a 1.5px `line` outline, `ink` text.
- `.rec` club record: `hawk` fill, `hawk-ink` text. `.pb` personal best: `sel-bg`/`sel-fg`. `.cb` course best: `mark` outline. `.top` top 10: `panel` fill, `good` text. `.new` first race: dashed `faint` outline, `muted` text. `.unof` unofficial (watch times): `faint` outline, `muted` text.
- At most three on one runner. Order: record, PB, course best, top 10.
