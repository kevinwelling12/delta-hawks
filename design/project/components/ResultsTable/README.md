# ResultsTable

Meet results, records and Course PRs: hairline table, tabular figures, Hawks rows highlighted.

- Wrap in `.scroll` so wide tables scroll inside themselves. On phones the first column sticks and the table bleeds to the edge.
- Number columns get `.n` (right aligned). Headers are 13px bold `muted`. Mile pace goes under the time in a `small`.
- A Delta Hawks row gets `tr.hawk`: `hawk-row` fill, weight 600, 4px `mark` edge.
- Group by race with `tr.venue` (condensed title, date in a span).
- Never use zebra stripes or cell borders.
