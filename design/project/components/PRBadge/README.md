# PRBadge

A small PR tag before a race name, and the athlete-page race history list it sits in.

- `.prb` is `sel-bg` with `sel-fg` text in the `badge` style, `radius-sm`. `.prb.old` marks a PR since beaten: outline only, `faint` text.
- `.list` rows: `.ln` name, `.lm` meta, `.lt` time in the `figure` style (30px) with mile pace under it. One row per item, no sideways scroll.
