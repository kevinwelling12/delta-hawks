# StatFigures

A row of numbers, each under a 3px `hawk` rule instead of a box.

- `.kv` grid of `div > b + span`. `b` is the `figure` style, `span` is `meta` in `muted`.
- Columns fill at 140px minimum. Use for three to five numbers that sum up an athlete or season.
- Write the number as a runner reads it; put the unit in the label. `.pos` (`good`) and `.neg` (`bad`) color a gain or loss.
