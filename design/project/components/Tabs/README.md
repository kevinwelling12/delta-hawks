# Tabs

Sticky section tabs on the `head` band, directly under the Header.

- Buttons with `role="tab"` and `aria-selected`. Unselected `band-tab`, selected `band-ink` with a 3px `hawk` underline. Labels in the `tab` style.
- Sticks at `top: env(safe-area-inset-top)`. Scrolls sideways on phones with the scrollbar hidden; add `.more` to `.tabs-in` to fade the right edge while tabs overflow.
- Show a tab only when its data exists (Simulation needs simulations, This week needs the blog post).
- Keep labels to one or two words a coach would say.
